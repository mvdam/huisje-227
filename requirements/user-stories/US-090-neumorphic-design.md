# US-090: Capfun Brand Card-Based Design

**As a** visitor,
**I want to** see a modern card-based design matching the Capfun de Bongerd brand,
**so that** the site feels professional, fresh, and consistent with the park's identity.

## Feature Area

[Visual Design](../10-visual-design.md)

## Acceptance Criteria

- Cards and prominent interactive elements use the shared Buitenleven shadow tokens for subtle depth
- Input fields and textareas have a 1px solid border and a clearly visible focus ring
- Components use the shared radius scale: 12px compact, 16px cards and 24px pill-shaped actions
- Shadows are subtle and centered
- Hover and pressed states transition between shared shadow tokens with 200–300ms ease
- The design uses white/sand surfaces, moss green (`#4A7C59`) and clay CTA accents (`#C4703E`)
- The overall effect is clean and modern, not heavy or over-shadowed
